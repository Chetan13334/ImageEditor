# 🖼️ Image Editor Web App

A lightweight and responsive Image Editor built with HTML, CSS, and Vanilla JavaScript. Users can upload an image, apply filters (brightness, saturation, inversion, grayscale), rotate, flip, reset changes, and download the edited image — all in a clean and interactive UI.

## 🚀 Features

- 📤 Upload and preview image
- 🎛️ Apply filters:
  - Brightness
  - Saturation
  - Inversion
  - Grayscale
- 🔄 Rotate left/right
- ↔️ Flip horizontally/vertically
- ♻️ Reset to original state
- 💾 Download the edited image

## 🧰 Tech Stack

- **HTML5** – Markup structure
- **CSS3** – Styling and layout (Responsive design using Flexbox)
- **JavaScript (Vanilla)** – DOM manipulation and core logic
